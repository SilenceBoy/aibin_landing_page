# 《个人品牌展示页改版方案 V2.1（1.6 版本）》

**适用对象：你本人 / 前端研发**
**目标：聚焦核心联系渠道，规范全站扫码弹窗交互，页脚网格化升级，实现视觉降噪与全站体验闭环**

在完成了 1.5 版本的核心功能和结构升级后，我们在 1.6 版本中进行了更具针对性的内容重构和交互升级。本次升级的目标非常明确：
1. **统一全站联系渠道的交互模型**，不再让微信、公众号、小红书的点击入口产生行为割裂。
2. **ContactCTA 联系区域视觉降噪**，让用户的注意力聚焦于核心联系渠道（邮箱、加微、公众号、小红书）。
3. **页脚（Footer）全面网格化升级**，将“我的站点”友情链接列表优雅收拢至页脚，形成四栏式的现代网格布局。

---

# 一、改版目标与升级要点

## 1.1 扫码交互大一统 (微信、公众号、小红书)
* **现状分析**：原微信、公众号与小红书的交互各不相同，微信可能需要用户手动添加，或者缺乏统一的指引，极易造成用户流失。
* **改版方案**：
  * 将所有需要展示二维码扫码的动作，在全站（ContactCTA 区域与 Footer 区域）统一规范为**拉起精美扫码 Modal 弹窗**。
  * 三个渠道对应三张图片资源：`src/assets/wx.JPG`（微信）、`src/assets/wxgzh.JPG`（公众号）、`src/assets/xhs.JPG`（小红书）。

## 1.2 字体字重降噪与体验微调
* **字重降噪**：全站的“silence52168”（微信号）、“Bin哥AI跃迁手记”（公众号）、“Bin哥的AI跃迁”（小红书）等锚点文字**全部取消加粗**，维持与正文协调一致的 `font-normal`（正常字重），使页面整体视觉节奏更轻盈高级。
* **微信高亮指引**：微信扫码弹窗内额外加注温馨提示：`添加微信请务必注明：你的行业和你的需求`，并搭配高亮呼吸灯脉冲动效（`animate-pulse`），确保高意向用户能提供有效信息。
* **自媒体极简扫码**：公众号与小红书弹窗仅聚焦于二维码本身，不呈现额外提示，提供无负担的关注体验。

## 1.3 友情链接迁移与四栏式页脚（Footer）升级
* **ContactCTA 视觉减负**：原 ContactCTA 卡片下方的“我的站点”友情链接超链接全面移除。
* **Footer 升级为四栏现代布局 (`grid-cols-4`)**：
  * **第一栏（品牌定位）**：展示“Bin哥 - 把 AI 变成学习力、生产力和实际结果。”
  * **第二栏（快速导航）**：首页各锚点极简导航。
  * **第三栏（联系我）**：邮箱，以及全部支持弹窗触发的微信号、公众号和小红书入口，与 ContactCTA 遥相呼应，达成全站交互闭环。
  * **第四栏（我的站点）**：友情链接的最终承接，以极简精致列表呈现。

## 1.4 友情链接文案优化
为了使个人站点的呈现更具“结果导向”与“品牌专业度”，我们将链接的文字描述进行了全面升华：
* “AI 写真网站” ➔ **“AI 写真创作站点”**
* “AI 知识库” ➔ **“AI 知识站点”**
* “GitHub” ➔ **“GitHub 站点”**
* “AI 新闻周报” ➔ **“AI 新闻周报站点”**

# 二、给研发的修改说明

## 2.1 整体改动点汇总

### 1. `src/pages/HomePage.tsx` [MODIFY]
* **核心职责**：管理全局扫码弹窗状态 `activeModal`。
* **修改细节**：
  * 引入 `wx.JPG`、`wxgzh.JPG` 与 `xhs.JPG` 三张本地图片资源。
  * 使用 React `useState<'wechat' | 'gzh' | 'xhs' | null>(null)` 作为统一的弹窗类型控制器。
  * 编写通用 `AnimatePresence` + `motion.div` 弹窗组件，背景应用超高质感的 `backdrop-blur-sm` 高斯模糊。
  * 条件渲染：
    * 微信模式（`wechat`）时，渲染高亮警示提示语：“添加微信请务必注明：你的行业和你的需求”。
    * 公众号和小红书模式时，使用极简无文案二维码渲染结构。

### 2. `src/components/ContactCTA/ContactCTA.tsx` [MODIFY]
* **核心职责**：移除友情链接，只保留关键联系方式并接入弹窗触发。
* **修改细节**：
  * 移除组件底部的“友情链接”相关链接渲染，仅保留“联系方式”大区。
  * 微信号、公众号、小红书文本使用普通字重（正常粗细，避免使用 `font-bold` 或 `font-semibold`）。
  * 分别绑定点击事件，通过 `onOpenModal` 传出 `'wechat'`、`'gzh'`、`'xhs'` 三个事件，通知父组件拉起弹窗。

### 3. `src/components/Footer/Footer.tsx` [MODIFY]
* **核心职责**：重构页脚为四栏布局，同时补齐联系弹窗和友情链接。
* **修改细节**：
  * 页脚网格样式升级：`<div className="grid md:grid-cols-4 gap-8 pt-8">`，完美适配 PC 端四栏并排与移动端响应式堆叠。
  * **第三栏（联系方式）**：与 ContactCTA 组件逻辑对齐，将微信号、公众号、小红书锚点全部改为 `<button>` 并绑定 `onOpenModal`，统一全站交互逻辑。
  * **第四栏（我的站点）**：渲染从 `homeContent.js` 加载的最新友情链接信息，链接文案采用最新优化版本，且全部采用 `target="_blank"` 在新窗口安全打开。

### 4. `src/content/homeContent.js` [MODIFY]
* **核心职责**：友情链接文字及元数据调整。
* **修改细节**：将外部链接对应的中文字符修改为：“AI 写真创作站点”、“AI 知识站点”、“GitHub 站点”、“AI 新闻周报站点”。

# 三、组件设计与状态伪代码

以下为本次改动的关键逻辑骨架，方便后续复查和扩展：

```tsx
// HomePage 状态控制与渲染
const [activeModal, setActiveModal] = useState<'wechat' | 'gzh' | 'xhs' | null>(null)

// 弹窗内部渲染逻辑
<h3>
  {activeModal === 'wechat' && '加微信联系我'}
  {activeModal === 'gzh' && '关注微信公众号'}
  {activeModal === 'xhs' && '关注我的小红书'}
</h3>

{activeModal === 'wechat' && (
  <p className="text-sm font-semibold mb-4 text-rose-500 animate-pulse">
    添加微信请务必注明：你的行业和你的需求
  </p>
)}

<img 
  src={
    activeModal === 'wechat' ? wxImg :
    activeModal === 'gzh' ? wxgzhImg :
    xhsImg
  } 
  alt="二维码" 
/>
```

# 四、交付验证计划

为了保证 1.6 版本成果的绝对可靠，我们制定并执行了以下验证规程：

### 4.1 自动构建与类型验证
在根目录执行生产构建命令：
```bash
npm run build
```
**验证标准**：
* TypeScript 编译器（`tsc`）无任何报错。
* Vite 打包工具 100% 成功生成 `/dist` 目录。
* 没有缺失的图片资源引入报错。

### 4.2 响应式与交互验证 (Playwright / 手动)
1. **PC 端展示**：
   * 检查 `ContactCTA` 区域是否清爽、无友情链接冗余。
   * 页脚是否正确排布为左右四等分布局，在宽屏下间距优雅。
2. **移动端适配**：
   * 页脚四栏在小屏下能够流畅重构为单列垂直堆叠，无重叠，无视口溢出。
3. **Modal 弹窗与关闭交互**：
   * 点击全站任何一处微信号、公众号或小红书按钮，遮罩层和弹窗顺滑拉起。
   * 点击弹窗外部半透明背景、或右上角 `X` 按钮，弹窗能够被流畅销毁，状态复位为 `null`。
