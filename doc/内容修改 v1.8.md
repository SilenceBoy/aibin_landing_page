# 二、改动详情

## 2.1 新增阿里巴巴履历背书

在首屏右侧「Professional Profile」卡片中，`Bin哥` 姓名下方新增一行铜色强调文字：

> 前阿里巴巴本地生活技术经理

**放置理由**：该卡片是首屏唯一的人物身份区，访问者视线从头像落到姓名后自然向下，是背书信息的最佳承接位。用铜色（`var(--accent)`）+ `font-semibold` 与下方灰色描述段拉开层级，不抢主标题。

**文案长度**：初版为「前阿里巴巴本地生活订单支付领域技术负责人」（20 字），在移动端窄卡片内折行且末字「人」单独成行，最终精简为 13 字，桌面端与移动端均单行显示，无需额外的响应式字号处理。

## 2.5 首屏视觉容器高度适配（布局修复）

`.hero-visual-note` 为绝对定位、底部锚定、向上撑高。2.1 新增一行后卡片高度增加约 36px，在 `lg` 断点与顶部圆形头像 `.hero-profile-orb` 产生 103×30px 重叠，卡片 90% 不透明背景会遮挡人像下缘。

修复方式：`.hero-visual-stage` 的 `min-height` 由 `34rem` 提升至 `37rem`，并将卡片内姓名下边距 `mb-2 → mb-1`、背书行下边距 `mb-3 → mb-2` 微调。

`@media (max-width: 640px)` 下的 `31rem` 覆盖规则不受影响。

## 2.6 区块背景色改为严格交替（视觉修复）

页面各区块通过 `var(--background)`（`oklch(0.965)`，浅）与 `var(--muted)`（`oklch(0.925)`，深）交替来区分层次，但改动前有 4 处相邻区块背景相同，导致视觉上粘连成一整块：

改动前：`Hero(浅) → Outcome(浅) → HardProof(深) → CaseHighlights(浅) → ProjectMetrics(浅) → Certifications(深) → WaysToCollaborate(深) → Process(浅) → ContactCTA(浅) → Footer(深)`

以 Hero 为浅色起点、Footer 为深色收尾推导，翻转 5 个区块即可得到严格交替：

| 区块 | 改动前 | 改动后 |
|------|--------|--------|
| Hero | 浅 | 浅（不变） |
| Outcome | 浅 | **深** |
| HardProof | 深 | **浅** |
| CaseHighlights | 浅 | **深** |
| ProjectMetrics | 浅 | 浅（不变） |
| Certifications | 深 | 深（不变） |
| WaysToCollaborate | 深 | **浅** |
| Process | 浅 | **深** |
| ContactCTA | 浅 | 浅（不变） |
| Footer | 深 | 深（不变） |

**兼容性说明**：`.soft-panel` 使用半透明渐变，会随所在区块背景变化。翻转涉及的区块中，`CaseHighlights` 与 `WaysToCollaborate` 含 soft-panel 卡片，两种底色此前均有区块在用（`WaysToCollaborate` 用深底、`ContactCTA` 用浅底），故翻转后对比度均在既有验证范围内；`Outcome`、`HardProof`、`Process` 为纯边框行式布局，无内嵌面板，不受影响。
